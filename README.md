# DouDian 天猫新品采集表

当前版本：**v1.1.0**。

在天猫店铺的“新品”排序列表采集 **店铺名称、商品标题、商品链接**，跨店去重、预览表格，导出 Excel / WPS 可打开的 CSV。


## v1.1.0 适配

- 支持 `div.title--PtjUKgj2[title] > span`，选择器匹配 `title--` 前缀，不固定动态后缀。
- 从标题向上寻找最近的 `[data-item-id]` 或 `[data-itemid]` 商品容器。
- 优先使用完整 `title` 属性和容器商品ID，生成 `https://detail.tmall.com/item.htm?id=商品ID`。
- 保留旧版商品链接及 React 卡片数据的回退识别。
- 元数据和操作面板均标明 v1.1.0。详细变更见 [CHANGELOG.md](CHANGELOG.md)。

## 数据与限制

- 导出字段：店铺名称、商品标题、商品链接、商品ID、店铺地址、采集时间、来源页面、列表口径。
- “新品”指用户确认的新品排序列表，不保证最近 N 天上架，也不代表新品标签。
- 采集时间为首次采集的 UTC 时间，不是上架时间。表格按店名及首次采集时间排列，不保证保留页面排名。
- 只采集当前页面已加载的数据；登录、加载和分页会影响完整性。不自动登录、不自动翻页。
- 同店铺同商品ID去重；缺少可识别商品链接的卡片会提示并跳过。
- 数据存在本机篡改猴 GM 存储中，不上传服务器，不读取密码、Cookie 或令牌。建议依次操作店铺，导出后再清空。
- CSV 使用 UTF-8 BOM，文本做 CSV 转义及公式注入防护。
- 已核对未登录页面 DOM 和用户提供的登录后标题元素；完整登录会话下的真实篡改猴端到端流程尚未验证。

## 测试

需要 Node.js 18 或更新版本：

```sh
npm install
npm test
```

测试包括商品链接规范化、嵌套商品数据、用户提供的标题结构、商品容器去重、缺失链接处理及 CSV 转义。
